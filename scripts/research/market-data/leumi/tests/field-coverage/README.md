`analyze-field-coverage.js`

## מטרה

למדוד על snapshot מלא:

- present / missing.
- null / undefined / empty.
- usable coverage.
- zero count.
- types.
- distinct values.
- min/max.
- דוגמאות.
- השוואת fields מקבילים בין שני endpoints.
