# Scripts

כלי עזר והרצות שאינם קוד production.

## מבנה

- `research/` — probes, recorders, demos ובדיקות מחקריות.
- קוד production עתידי **לא** נכנס לכאן; מקומו יהיה תחת `src/`.
- tests אוטומטיים של קוד production עתידי **לא** נכנסים לכאן; מקומם יהיה תחת `tests/`.

כל תת-תיקייה חייבת לכלול `README.md` שמסביר מה יש בה, איך מריצים ומה הסטטוס של הקוד.
