Reason:


This is a structural cadence-selection effect: most next observations occur after the 5-second deadline.

`20s–120s` have 100% non-edge strict endpoint availability in this dataset; their overall loss is session-edge censoring.

## 5. Endpoint-tolerance decision

For the current V1 research dataset, use one global timestamp-only tolerance:

~~~text
endpointToleranceMs = 7,229
~~~

Selection rule:

~~~text
max(
  p99(endpointTimingErrorMs)
  across H = {10,20,30,40,50,60,90,120}s
)
= 7,229ms
~~~

Why one global value:

- it is derived only from timestamp/cadence evidence, not market outcomes;
- it avoids horizon-specific post-hoc tuning;
- by construction it retains at least 99% of the already strict-evaluable endpoint candidates at every 10–120s horizon;
- observations after the deadline remain forbidden;
- the rare stale tail above this tolerance becomes `ENDPOINT_TOLERANCE_MISS`.

The same configured tolerance may be mechanically applied to the 5s row, but it does **not** repair the 5s availability problem. A missing pre-deadline sample stays missing.

This tolerance must be persisted with every research run.

If collection cadence materially changes, this value must be recalibrated rather than treated as universal.

### What this proves

Longer paths mechanically have more chances to contain a long sampling gap.

Therefore choosing:

~~~text
maxAllowedPathGap = max/p99 path gap of the longest horizon
~~~

would preserve coverage by allowing blind intervals up to ~13.6–15.4 seconds.

That is not automatically acceptable for short-horizon barrier ordering.

### Decision

Do **not** freeze `maxAllowedPathGap` from this summary alone.

The next measurement must report exact retained-path coverage under candidate **individual-gap** policies anchored to the observed cadence distribution:

~~~text
6,106ms  = global inter-observation p90
6,541ms  = global inter-observation p95
8,895ms  = global inter-observation p99
~~~

Then we can see the real coverage cost by horizon instead of guessing it from percentile tables.
