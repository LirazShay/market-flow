# D-003 — Adaptive work batches + explicit next-stage semantics

Status: Accepted / evolved

Decision:

Normal implementation scope is chosen by technical coherence and meaningful verification boundaries. There is no default requirement that one chat message equals one substep.

However, when the user explicitly writes:

~~~text
תמשיך לשלב הבא
~~~

the agent advances exactly one planned stage from the authoritative workstream status/roadmap and completes that stage's implementation, tests, required CI/checkpoint verification and status updates before advancing further.

The word:

~~~text
סיימתי
~~~

is reserved for completion of the full planned process/version requested by the user, not for an individual stage, checkpoint or mini-project.

Why:

- arbitrary message boundaries should not distort engineering work;
- explicit user stage control must still be respected;
- repository state must remain reviewable and resumable between chats.
