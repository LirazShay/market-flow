# זרימת הנתונים שנצפתה

## תמונה כללית

בדף המניות נצפו שתי קריאות מרכזיות:

~~~text
MapHeat2
   ↓
רשימת ניירות + סדר + שמות + מידע כללי
   ↓
PaperId[]
   ↓
GetSecuritiesData
   ↓
נתוני שוק מפורטים ועדכניים עבור אותם IDs
~~~

החיבור הלוגי בין הרשומות הוא:

~~~text
MapHeat2.PaperId == GetSecuritiesData.Key
~~~

## תפקיד MapHeat2

הקריאה כוללת פרמטרים של:

- page
- pageCount
- orderFieldName
- order
- indexIdArray
- filters נוספים

לכן היא משמשת לקביעת קבוצת התוצאות והסדר שלהן.

היא מחזירה גם מידע כללי על כל נייר, כולל שם, שער, BID/ASK, מחזור ומספר עסקאות.

## תפקיד GetSecuritiesData

הקריאה מקבלת:

~~~text
securityIds=id1,id2,id3,...
~~~

ומחזירה לכל Key מידע מפורט יותר כגון:

- שער אחרון
- שער בסיס
- BID1 / ASK1
- כמויות BID1 / ASK1
- מספר עסקאות יומי
- כמות בעסקה האחרונה
- גבוה/נמוך יומי
- זמני עדכון
- שדות נוספים של ספר פקודות

## התנהגות רענון שנצפתה

בהקלטת הרשת `GetSecuritiesData` הופיעה שוב ושוב עם רשימות IDs, בעוד `MapHeat2` הופיעה סביב יצירת/שינוי רשימת התוצאות ומעברי עמודים.

מכאן אפשר לתאר את ההתנהגות שנצפתה כך:

~~~text
MapHeat2
→ קביעת קבוצת הניירות

GetSecuritiesData
→ רענון הנתונים של אותה קבוצה
~~~

זו תצפית מתעבורת הרשת; לא נטען כאן שראינו את קוד המימוש הפנימי של האתר.
